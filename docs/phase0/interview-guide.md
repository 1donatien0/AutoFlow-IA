# Guide d'interviews — Phase 0

Objectif : 20 interviews terrain pour choisir un vertical et valider les tâches répétitives.

## Profil cible

- PME 5–50 employés
- Décideur opérationnel (gérant, directeur, office manager)
- Secteurs : compta, marketing, ingénierie, construction, juridique, immobilier

## Script (30–45 min)

1. **Contexte** : effectif, outils (email, CRM, ERP, Excel), volume emails/jour
2. **Journée type** : 3 tâches les plus chronophages
3. **Répétition** : quelles actions font >10×/semaine ?
4. **Douleur** : heures/semaine estimées, erreurs, retards clients
5. **Automatisation** : outils essayés (Zapier, etc.) — pourquoi abandonnés ?
6. **Budget** : sensibilité prix pour gain de X h/mois
7. **Données** : acceptation lecture seule emails/docs (RGPD)

## Grille de capture

| Champ | Exemple |
|-------|---------|
| Vertical | Cabinet comptable |
| Tâche répétitive | Relance factures impayées |
| Fréquence | 40×/mois |
| Temps unitaire | 15 min |
| Outils impliqués | Gmail, Excel |
| Priorité douleur | 1–5 |
